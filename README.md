# 🚒 消防及義消子女獎學金 AI 智慧審核網頁系統

基於 **Streamlit** 與 **Google GenAI SDK (Gemini 2.5 Flash)** 開發的多模態獎學金智慧審查與管理系統。

---

## 🌟 系統亮點

1. **多模態 AI 智慧擷取**：
   - 整合最新 Google GenAI SDK (`gemini-2.5-flash`)。
   - 同時讀取多張照片（申請表、成績單、戶口名簿、在職服務證明等）。
   - 自動提取：申請人家長姓名、身分證字號、子女姓名、申請組別、學期總平均（精確至兩位小數）、操行成績與 5 項必備附件。
2. **自動邏輯審查判定**：
   - **符合資格 (綠色)**：學期總平均 $\ge 80.0$ 且 5 項必備附件齊全。
   - **待補件 (黃色)**：有缺漏附件（標註缺件名稱）。
   - **不符資格 (紅色)**：學期總平均 $< 80.0$ 未達標準。
3. **「左圖右表」人機協作複核**：
   - 左側：原始申請文件與成績單高解析預覽（支援多頁切換）。
   - 右側：承辦人即時修正與編輯表單，數值更動時即時重新試算資格。
4. **標準 Excel 審核清冊匯出**：
   - 產出政府與公會標準格式的 `.xlsx` 活頁簿。
   - 包含彙總統計橫幅、狀態色彩標記、斑馬紋以及承辦人核章欄。
5. **內建示範模式**：
   - 一鍵載入 4 組擬真申請樣張與案例，免 API Key 亦可完整體驗。

## 🚀 快速啟動

### 1. 安裝套件
```bash
pip install -r requirements.txt
```

### 2. 設定 Gemini API Key
可透過環境變數或直接在網頁側邊欄填入：
```bash
# Windows PowerShell
$env:GEMINI_API_KEY = "您的_GEMINI_API_KEY"
```

### 3. 啟動 Streamlit 服務
```bash
streamlit run app.py
```

瀏覽器將自動開啟 `http://localhost:8501`。
